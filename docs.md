## 📋 Market API - Документация (Версия 4.1)

**Базовый URL:** `http://localhost:5000/api`

---

## 📊 Формат ответа

### Успешный ответ (200 OK):
```json
{
    "data": { ... }
}
```

или для списков:
```json
{
    "data": [...],
    "pagination": { ... }
}
```

### Ошибка (400+):
```json
{
    "error": "Описание ошибки"
}
```

---

## 🔐 Аутентификация

Для защищенных эндпоинтов требуется JWT токен в заголовке:
```
Authorization: Bearer <access_token>
```

### 8. ➕ Создание товара / Перепродажа
**POST** `/products`  
**Требуется токен**  
**Content-Type:** `multipart/form-data`

**Поля формы:**
- `title` (3-100 символов)
- `price` (10-10000 AC)
- `description` (до 1000 символов, опционально)
- `image` (файл изображения)

**Ответ при создании нового товара (201):**
```json
{
    "id": "85164644-1130-4058-9c6d-a80b78dcf595",
    "title": "Уникальный Товар #1",
    "description": "Описание товара",
    "price": 100,
    "photo_url": "/api/images/original/eac9a16b-6703-4b73-bc55-df6ad74f81ba",
    "created_at": "2026-04-04T17:15:06.239156",
    "on_sale": true
}
```

**Ответ при перепродаже (200):**
```json
{
    "id": "85164644-1130-4058-9c6d-a80b78dcf595",
    "title": "Уникальный Товар #1",
    "description": "Описание товара",
    "price": 100,
    "photo_url": "/api/images/original/eac9a16b-6703-4b73-bc55-df6ad74f81ba",
    "created_at": "2026-04-04T17:15:06.239156",
    "on_sale": true
}
```
*Примечания:*
- *Средства с баланса не списываются*
- *При перепродаже используется тот же эндпоинт — система автоматически определяет, новый это товар или уже существующий*
- *Хеш изображения проверяется на уникальность — одинаковые фото нельзя выставить дважды*
- *Водяные знаки навсегда блокируются — если изображение с водяным знаком уже было в системе, его нельзя выставить*

**Ошибки:**
- `400` "Нельзя выставлять изображение с водяным знаком"
- `400` "Вы не являетесь владельцем этого изображения"
- `400` "Товар уже выставлен на продажу"
- `400` "Это изображение уже выставлялось ранее"

### 9. 💰 Покупка товара
**POST** `/products/{product_id}/buy`  
**Требуется токен**

**Ответ (200):**
```json
{
    "id": "85164644-1130-4058-9c6d-a80b78dcf595",
    "title": "Уникальный Товар #1",
    "description": "Описание товара",
    "price": 100,
    "photo_url": "/api/images/original/eac9a16b-6703-4b73-bc55-df6ad74f81ba",
    "creator": {
        "id": "dded37fe-0c12-4605-8b35-92ee53428cef",
        "nickname": "seller_name"
    },
    "purchased_at": "2026-04-04T17:30:06.239156",
    "on_sale": false
}
```
*Примечания:*
- *Комиссия 5% сгорает, остальное получает продавец*
- *После покупки товар снимается с продажи (`on_sale = false`), новый владелец может перепродать его через тот же эндпоинт `/products`*

**Ошибки:**
- `400` "Недостаточно средств"
- `400` "Нельзя купить свой товар"
- `404` "Товар не найден" (если товара нет или он не в продаже)

## ⚠️ Ошибки и статус-коды

### Общие ошибки:
- `400` - Некорректный запрос
- `401` - Неавторизован (нет/неверный токен)
- `403` - Нет прав доступа
- `404` - Ресурс не найден
- `413` - Файл слишком большой (максимум 16MB)
- `415` - Неподдерживаемый тип данных
- `500` - Внутренняя ошибка сервера

### Бизнес-ошибки:
- "Недостаточно средств"
- "Превышен лимит активных товаров (8)"
- "Нельзя купить свой товар"
- "Товар уже выставлен на продажу"
- "Вы не являетесь владельцем этого изображения"
- "Нельзя выставлять изображение с водяным знаком"
- "Это изображение уже выставлялось ранее"
- "Цена должна быть от 10 до 10000 AC"
- "Название должно быть от 3 до 100 символов"
- "Нельзя объявить банкротство при балансе ≥ 100 AC"
- "Нельзя объявить банкротство с активными товарами на продаже"
- "Банкротство можно объявлять только 1 раз в день"
- "Сегодня бонус уже получен"
- "Баланс превышает лимит для получения бонуса (500 AC)"

## 🔧 Настройка и запуск

1. **Установка зависимостей:**
```bash
pip install -r requirements.txt
```

2. **Настройка .env файла:**
```env
FLASK_ENV=development
DATABASE_URL=sqlite:///market.db
SECRET_KEY=your-secret-key-change-in-production
JWT_SECRET_KEY=your-secret-key-change-in-production
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRES=3600
JWT_REFRESH_TOKEN_EXPIRES=2592000
```

3. **Запуск сервера:**
```bash
python main.py
```

4. **Заполнение тестовыми данными (опционально):**
```bash
python seed.py
```

5. **Запуск через Docker:**
```bash
sudo docker build -t school-art-market .
sudo docker run -d --name art-market -p 5000:5000 school-art-market
```

## 📞 Поддержка

### Типичные проблемы:
1. **"Токен отсутствует"** - добавьте заголовок `Authorization: Bearer <token>`
2. **"Файл слишком большой"** - максимальный размер 16MB
3. **"Недостаточно средств"** - проверьте баланс пользователя
4. **"Превышен лимит товаров"** - максимум 8 товаров на продавца
5. **"Изображение не найдено"** - убедитесь, что файл существует и у вас есть права доступа
6. **"Нельзя выставлять изображение с водяным знаком"** - водяные знаки навсегда блокируются системой

### Отладка:
- Проверьте формат JSON в теле запроса

## 🆕 Что нового в версии 4.1

- **Защита от дублирования изображений** — система вычисляет SHA256 хеш каждого загруженного изображения и блокирует повторные выставления
- **Блокировка водяных знаков** — если изображение с водяным знаком когда-либо было в системе, его нельзя выставить снова
- **Перепродажа товаров** — купленный товар можно выставить на продажу через тот же эндпоинт `/products`
- **Новый флаг `on_sale`** — заменяет `is_sold` (true = товар в продаже, false = не в продаже)
- **Загрузка хешей в память** — при старте сервера все хеши загружаются в RAM для быстрой проверки
